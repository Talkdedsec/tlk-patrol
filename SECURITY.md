# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use **Security > Report a vulnerability** on this repository, or write to talkdedsec@proton.me.

---

# Güvenlik Politikası

## Zafiyet bildirme

Lütfen herkese açık bir issue açma. Bu repodaki **Security > Report a vulnerability** bağlantısını kullan ya da talkdedsec@proton.me adresine yaz.
